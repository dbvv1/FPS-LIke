## 既有换弹零件轨道的真实采用

沿同一整合分支继续，不下载新素材、不改源 GLB、不另设旁置入口。训练 View 现加载固定 `fp-arms-rx24.glb`，校验原188,088字节／SHA-256后才替换程序步枪；手枪和失败回退保留原模型。源掌部先严格排除合并的袖管三角，原程序袖管仍是唯一袖管；不是把整条胳膊当手平移。

两条 LINEAR 平移轨道均为1.9秒闭合，无skin。每次取轨道首帧差量，再按真实换弹进度采样到弹匣／枪栓位移，避免源节点舍入差带来的手部基准跳动。source-rifle模块不播放idle/fire根轨道，既有根位姿不会重复叠加。

- 实际源键：弹匣约20%–25.3%拔出，52.6%–57.9%插回；与原说明文稿的阶段不同，以GLB为准。源线性拔插比旧smooth轨道更急，视觉是否更好仍未知。
- 1901个归一化样本、719个弹匣接触样本核对原始键插值与实际模型位置，拔插期间grasp=1；双袖管均可达，最大肩袖口距离0.57454m，距0.58m上限仅约5.46mm，必须实机看接触、袖管和屏幕覆盖。
- 实际View核替换后只保留两条程序袖管、步枪／手枪切换、换弹打断归位、reset重新挂接和独立加载失败回退；缺轨、非线性、未归位或侧移不兼容资源拒用，晚到资源不会复活退出视图。
- 默认声音阶段未变：退匣声在换弹起始，比源弹匣开始移动早约380ms；归匣声约56%、枪栓声约78%。默认、手枪、CPU和加载失败路径仍保留旧行为。
- 同一实际训练消费者增加可回退的 `reloadAudio=source-rifle-v1`，仅精确单值启用；删除参数即回默认。源步枪成功呈现后，按当前GLB键推导的0.38／1.00／1.44秒三个运动起点触发原退匣／入匣／枪栓波形，音量不变。实际View回执携带同一帧的源进度、reloadEnd和武器代际，Soundscape不另开计时器、不修改Game。
- 每次真实reload开始锁定所选时序，中途源加载完成不切换；静音、不可呈现或跨越过久的阶段被消费而不补播。切枪取消、同tick单切／双切回、reset与迟到资源不得泄漏旧退匣声。实际Game＋View＋Soundscape＋音频设备替身验证三声各一次、触发距源起点不超过一模拟tick，默认／缺回执仍原行为。
- 这只证明候选内的调度时点，不证明真实设备延迟、GPU画面、声音清晰度或听感提升。源线性动作更急的风险仍在，必须同段视听验收。
