# 当前品质：暂停菜单与连续射击的输入收口

暂停菜单现在不会把键盘焦点送到背后的游戏控件；设置草稿可先取消，再回到主按钮继续。自动射击按已处理的按下/松开时间线消费输入，避免低帧率在松开后补算时吞掉本应发出的尾发。地面保留已发布的混凝土版本，本轮不改场景资产或武器数值。

## 最大差距与下一轮

院落仍以低细节大方墙和硬质角色构成，整体结构、比例与材料层次离参照明显更远；下一轮优先这些整体画面差距，不继续增加小按钮。固定手指、僵硬敌人姿态、急停点射的人体手感与声音也仍未完成。

本版只合入已审菜单与输入，保留原地面和实时渲染；木箱/新静态光照整合未进入本版。该组合此前的页面崩溃证据仍保留；本次无录像条件下通过，不能反推旧崩溃由录屏或任何单一原因造成。

85 项串行测试、生产构建/类型检查、无画面 smoke 与上述普通 UI 路线通过，是交付门槛，不是 CS2 整体品质完成。
