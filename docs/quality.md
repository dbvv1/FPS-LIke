# 待实玩候选：移动、急停与短连射同一条规则链

2026-10-27，基于正式版 `a97d57281dd6c6d941c6a6bef732dadf2953f2f4` 的规则 v2 候选；本轮不改场景、枪模资产或输入瞄准。**源码与无画面回归已过，未做本候选的正常键鼠、浏览器、声音或当前 CS2 对照，不据此宣布手感或品质达标。**

- 松键不再瞬间静止；反向键可更快制动。射击散布读当刻碰撞后速度，顶墙不会累积虚假跑速。
- 步枪原创建模的连续 24 发后坐不再第 7 发归零，停止后连续恢复；弹道、机器人已有压枪能力与准星共用精度状态，枪模 kick 不二次改变弹道。
- 中间时间查询从固定运动检查点重算；已修独立审查发现的“无关 aim 改变角落绕行方向”问题。原 120 tick 复现相差 3.559 场景单位，修后位置、速度、精度与脚步逐 tick 相同。滑停后的自动交互资格固定 tick 检测，明确交互与已运行计时器仍精确结算，队友接手旧合同保留。

## 无画面验证与数值变化

## 接收门槛仍是实际操作

固定同一掩体，以正常键鼠完成“侧移窥角 → 松键／反向制动 → 首发 → 3–5 发压枪 → 退回装填 → 再出枪”，与正式版及当前 CS2 分别比较。记录停止／恢复时机、准星信息、对枪节奏、换弹阶段与声音，交非作者复评；未完成前只称候选。CPU 或自动命令带不代替这项验收。

## 最大差距与下一轮

院落仍以低细节大方墙和硬质角色构成，整体结构、比例与材料层次离参照明显更远；下一轮优先这些整体画面差距，不继续增加小按钮。固定手指、僵硬敌人姿态、急停点射的人体手感与声音也仍未完成。
