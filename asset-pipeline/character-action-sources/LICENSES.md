# 许可说明

本目录只包含两类许可材料：

1. `sources.md` 第 5 节：候选来源的许可范围、覆盖对象与风险；
2. `sample/kaykit/`：KayKit 小样的原许可文本。

## 小样许可

| 文件 | 许可 | 原文 |
|---|---|---|
| `sample/kaykit/Knight.glb` | CC0 1.0 | `sample/kaykit/LICENSE-KayKit-Adventurers.txt`（KayKit Adventurers 官方 LICENSE.txt） |
| `sample/kaykit/Med_CombatRanged.glb`、`Med_MovementAdvanced.glb`、`Med_General.glb` | CC0 1.0 | `sample/kaykit/LICENSE-CC0-1.0.txt`（sketchpunklabs/kaykit_char 仓库 LICENSE，完整 CC0 法律文本） |

CC0 1.0 允许复制、修改、商用与再分发，不要求署名。本仓保留作者与包名仅作来源记录。KayKit 官方 README 另写明 “Free for personal and commercial use, no attribution required. (CC0 Licensed)”。

## 其他候选的许可状态

- **Quaternius**：包页多标 CC0，OGA 作者上传包内含 CC0 1.0 `License.txt`；但 `quaternius.com/license.html` 自 2026-08-28 起为 QAL v1.0，禁止把素材本身（含修改后）作为独立 asset pack/stock file 再分发。**冲突未解决**，入公开仓库前必须由 dot 决定或向作者确认。
- **Kenney**：CC0。
- **Mesh2Motion**：代码 MIT；美术 `LICENSE-CC0.MD` 覆盖 `models/blend/rigs/animations`。
- **Microsoft Rocketbox**：MIT（`LICENSE.md`）。
- **100STYLE**：CC BY 4.0，需署名。
- **CMU Motion Capture**：原始页写 “free for all uses”；再分发条款需复核。
- **OpenGameArt 单项**：逐项 CC0 / CC-BY 3.0/4.0 / CC-BY-SA / GPL，见 `sources.md` T1/T4。
- **Sketchfab**：逐模型 CC BY 4.0 或 Free Standard；下载需登录，未尝试。
- **Fab / Unity / UE 商店**：商业 EULA、需账号；不允许把原始素材作为独立文件再分发。
- **Mixamo / Adobe**：可商用、免版税、无需署名，但不可把原始角色/动画当独立资产再分发；需 Adobe 登录。
- **二手转载（cgais/budeco/B 站/爱给网）**：自述“仅供学习/禁止商用/未标许可”，不构成许可来源。

## 不做的事

- 不把 CC-BY 当 CC0；不把“免费下载”当“可再分发”。
- 不把镜像/二次组装当作者原页授权。
- 不把搜索摘要、视频或“看起来像换弹”当成可编辑 clip 的许可证据。
